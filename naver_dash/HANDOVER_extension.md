# 인수인계: 다차원 보고서 자동 다운로드 크롬 확장프로그램

요청자: 정순홍 팀장 (영업6팀). **코드 이야기는 아주 짧고 쉽게** 해주세요. 답변은 한국어.

## 왜 만드나
- 성과 진단 덱 툴(SEARCH AD DECK TOOL)에 넣으려면 신입이 네이버 광고센터 **다차원 보고서**를 종류·월별로 20개 넘게 받아야 합니다.
- 월 단위로 따로 받다 보니 **한두 달을 빠뜨리거나 잘못 받는 실수**가 계속 납니다. 이걸 없애는 게 목적입니다.

## 이미 된 것 (이 저장소 `naver_dash/`)
- `deck_export.py`: 네이버 검색광고 **API 키**로 덱 툴용 파일을 만듭니다.
  - 매체·소재, 성별, 연령대, 쇼핑 소재목록 → **기간 전체 자동** (검증 완료)
  - 검색어, 요일·시간대 → 광고비는 전체, **구매완료는 최근 약 45일만** (API 의 전환 상세 보고서 보존 기간 한계)
- 즉 확장프로그램이 꼭 채워야 하는 건 **45일보다 오래된 기간의 검색어 / 요일·시간대 보고서**입니다.
  (편의상 모든 종류를 받게 해도 됩니다. 덱 툴은 중복 업로드를 감지합니다.)

## 확장프로그램이 할 일
1. 광고센터(ads.naver.com)에 **로그인된 브라우저에서** 실행. 비밀번호는 절대 저장·입력하지 않음.
2. 계정·기간(예: 4개월)을 고르면, 보고서 종류별로 **네이버가 허용하는 기간 단위로 잘라서** 빠짐없이 차례로 내려받기.
   - 팀장 설명: 종류마다 한 번에 받을 수 있는 기간이 다름. 매체·소재·검색어는 4개월 한 번에, 요일·시간대·성별·연령대는 30일 단위.
   - 지표는 덱 툴 필수 지표를 반드시 체크: 노출수, 클릭수, 총비용, 총 전환수, 구매완료 전환수, 구매완료 전환매출액, 평균노출순위.
3. 다 받은 뒤 **빠진 달이 없는지 목록으로 보여주기** (받은 기간 표).
4. 파일 이름에 계정·종류·기간을 넣어 한 폴더에 저장 → 덱 툴에 통째로 끌어다 놓기.

## 먼저 할 일 (팀장 도움 필요)
- 개발 세션은 광고센터에 로그인할 수 없습니다. 팀장에게 **개발자 도구 Network 기록(HAR)** 을 받아 실제 요청 구조를 파악해야 합니다.
  1. 크롬에서 다차원 보고서 화면 열기 → F12 → Network 탭 → "Preserve log" 체크
  2. 보고서 조건(검색어, 1개월, 지표) 설정 후 다운로드 1번
  3. 요일·시간대로도 1번 더
  4. Network 목록 우클릭 → "Save all as HAR" → 파일 업로드
  - HAR 에는 로그인 쿠키가 들어 있으니 **업로드 후 바로 로그아웃·재로그인**하도록 안내하고, 저장소에는 절대 커밋하지 않기.
- 확인된 사실: 광고센터 검색광고 화면은 `gw.searchad.naver.com`(로그인 쿠키 인증)을 내부적으로 씁니다. API 키로는 이 기능을 부를 수 없습니다.

## 덱 툴이 읽는 파일 형식 (확장프로그램이 받은 원본 그대로면 OK)
- CSV, 1행 = 제목에 기간 `…(2026.06.01.~2026.06.30.)`, 2행 = 헤더. UTF-8 BOM(깨지면 EUC-KR).
- 종류 판별 컬럼: 검색어=`검색어`, 요일·시간=`요일별`+`시간대별`, 성별=`성별`, 연령=`연령대`, 매체=`매체이름`.
- `월별` 컬럼이 있으면 월을 그 값으로 나눔. 자세한 규칙은 덱 툴 인수인계(HANDOVER_search_ad_deck_tool.md) 3·11·12장.

## 주의
- 조회·다운로드만. 광고 설정을 바꾸는 요청은 절대 보내지 않기.
- 요청 사이에 쉬는 시간을 두어(예: 1~2초) 비정상 사용으로 보이지 않게.
- 네이버가 화면·내부 구조를 바꾸면 깨질 수 있음 → 실패 시 어느 보고서·기간이 안 받아졌는지 분명히 표시.
- 공개 저장소: 광고주 데이터·HAR·쿠키는 커밋 금지.
