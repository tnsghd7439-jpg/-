# 네이버 전담팀 원보드

팀 전용 시작 화면입니다. 탭은 계정별 실적, 개인별 액션플랜, 공지사항, 솔루션, 매체별 가이드, 캘린더, 팀 현황(팀장 전용)으로 구성됩니다.
구글 시트 + 앱스 스크립트로 돌아가므로 **보드를 쓰는 데 Claude 크레딧이 들지 않습니다.**

| 구성 | 위치 | 하는 일 |
|---|---|---|
| 보드 | `Code.gs`, `Index.html` | 구글 시트에 붙여서 웹 페이지로 배포 |
| 알리미 | `alerter/` 폴더 | 크롬 확장. 보드 창을 닫아도 공지·오늘 할 일 알림 |
| 실적 수집 | `alerter/mpai.js` | 팀장 크롬의 알리미가 매일 MP AI 매출을 시트로 보냄 |
| 인트라넷 보충 | `../mp_report/board_sync.py` | MP AI에 없는 매체(11번가·카카오·에이블리)만 인트라넷에서 보충 (GitHub Actions) |

> 이 저장소는 **공개**입니다. 팀원 명단, 매출, 토큰, 연결 코드는 절대 코드나 저장소에 넣지 말고 시트와 Secrets 에만 둡니다.

---

## 1. 보드 설치 (팀장, 20분)

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. 이름은 `네이버 전담팀 원보드`로 합니다. 이 시트가 데이터 저장소이며, **팀원에게 공유하지 않습니다.**
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 파일 `Code.gs`의 내용을 지우고, 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
4. 왼쪽 **파일 + → HTML**로 이름이 `Index`인 파일을 만들고 `Index.html` 내용을 붙여넣습니다.
5. 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다. 권한 요청이 뜨면 허용합니다.
   - 시트 탭 10개가 생기고, 실행한 사람(팀장)이 `팀원` 탭에 등록됩니다.
6. 시트 `팀원` 탭에 팀원을 한 줄씩 추가합니다.
   - `이메일`: 회사 구글 계정
   - `이름`: 화면에 보일 이름
   - `역할`: `팀장` 또는 `팀원`
   - `담당자명`: 이름을 적습니다. 실적은 MP AI 담당자 **이메일**로 연결되므로, `이메일`은 MP AI에 로그인하는 회사 메일과 같아야 합니다.
   - `사용`: `Y`
7. **배포 → 새 배포 → 웹 앱**을 두 번 만듭니다.
   - **보드용**: 실행 사용자는 `나`, 액세스 권한은 `mymp.co.kr 내 모든 사용자`. 이 주소를 팀원에게 공유하고, 시트 `설정` 탭의 `보드주소`에 넣습니다.
   - **외부 연결용**(알리미): 실행 사용자는 `나`, 액세스 권한은 `모든 사용자`. 이 주소는 `설정` 탭의 `알림주소`에 넣습니다.
     이 주소로 보드를 열면 로그인 정보가 없어서 화면이 나오지 않습니다. 정상입니다. 연결 코드가 있어야만 데이터를 주고받습니다.
8. 시트 `설정` 탭의 `솔루션폴더ID`에 솔루션 파일을 올릴 드라이브 폴더 주소를 붙여넣습니다. 이 폴더는 팀원에게 **보기 권한**으로 공유합니다.

**코드를 고친 뒤에는** 배포 → 배포 관리 → 연필 아이콘 → 버전을 `새 버전`으로 바꾸고 배포해야 반영됩니다. 그래야 주소가 바뀌지 않습니다.

## 2. 알리미 설치 (팀원 각자, 3분)

크롬 확장이라서 크롬이 켜져 있으면 보드 창을 닫아도 동작합니다. 크롬을 완전히 종료하거나 PC가 꺼져 있으면 알림이 오지 않습니다.

1. `alerter` 폴더를 PC에 내려받습니다.
2. 크롬 주소창에 `chrome://extensions`를 입력합니다. 오른쪽 위 **개발자 모드**를 켜고, **압축해제된 확장 프로그램을 로드**를 눌러 `alerter` 폴더를 고릅니다.
3. 보드 오른쪽 위 **알리미 연결**을 눌러 **코드 복사**를 합니다. 크롬 오른쪽 위 알리미 아이콘 → **연결 코드 설정**에 붙여넣고 저장합니다.
4. 윈도우 **설정 → 시스템 → 알림**에서 크롬 알림이 켜져 있는지 확인합니다.

알림 규칙은 다음과 같습니다.
- **공지**: 새 공지는 10분 안에 알립니다. 확인하지 않으면 1시간마다 다시 알리고, 클릭하기 전까지 알림이 닫히지 않습니다.
- **오늘 할 일**: 매일 `아침알림시각`(기본 9시) 이후 한 번 알립니다. 팀장에게는 승인 대기와 소통 필요 실패 건수도 함께 알립니다.

## 3. 실적 자동 수집 — MP AI (팀장, 5분)

MP AI는 회사 구글 로그인 뒤에 있어서 서버가 직접 접속할 수 없습니다. 그래서 **팀장 크롬의 알리미**가 팀장 로그인 상태로 MP AI를 조회해 시트로 보냅니다. Claude 크레딧은 들지 않습니다.

1. 팀장 크롬에서 MP AI에 로그인해 둡니다. 평소처럼 쓰시면 됩니다.
2. 팀장 알리미를 연결합니다(2장과 같은 방법). 팀장 코드로만 매출을 보낼 수 있습니다.
3. 시트 `설정` 탭에서 월간보고와 같은 기준을 넣습니다.
   - `VAT포함매체`: 비워둡니다. MP AI가 이미 공급가액을 줍니다.
   - `제외계정`: 월간보고에서 빼는 광고주ID들(쉼표로 구분)
   - `절반반영계정`: 보통 비워둡니다. MP AI가 매출공유 비율을 이미 반영합니다.
   - 이 값들은 공개 저장소에 올리지 말고 **시트에만** 넣습니다.
4. 알리미 아이콘 → **처음: 이력 채우기**를 한 번 누릅니다. 최근 62일 일별과 7개월 월별을 가져옵니다.
5. 이후에는 매일 `수집시각`(기본 11시) 이후 첫 확인 때 자동으로 가져옵니다. 팀장 크롬이 그 시각에 꺼져 있으면, 켜진 뒤 10분 안에 가져옵니다.

실패하면 알림이 뜹니다(대부분 MP AI 로그인이 풀린 경우). MP AI에 다시 로그인하고 알리미에서 **지금 가져오기**를 누르면 됩니다.

> MP AI '내 광고매출'과 같은 조회(내 광고주 + 팀원 전체)를 씁니다. 금액은 MP AI가 계산한 공급가액이고, 쿠팡은 원래 금액입니다. 매출공유는 MP AI의 공유 비율대로 반영됩니다. MP AI에 아직 없는 매체(11번가·카카오·에이블리)는 아래 인트라넷 보충으로 채웁니다.

### 인트라넷 보충 — MP AI에 없는 매체 (팀장, 10분)

11번가·카카오·에이블리는 MP AI에 아직 없어서 인트라넷에서 보충합니다. 월간보고 규칙과 같은 방식입니다. GitHub Actions가 매일 오전 11:10에 자동으로 실행하므로 Claude 크레딧은 들지 않습니다.

1. 시트 `설정` 탭의 `수집토큰` 값을 복사합니다. `setup` 때 자동으로 만들어집니다.
2. GitHub 저장소 **Settings → Secrets and variables → Actions**에 4개를 등록합니다.
   - `MP_ID`, `MP_PW`: 인트라넷 계정
   - `BOARD_URL`: 외부 연결용 배포 주소
   - `BOARD_TOKEN`: 수집토큰 값
3. **Actions → board-sync → Run workflow**에서 `backfill`을 체크하고 한 번 실행합니다.
4. 인트라넷 매출은 담당자 **이름**으로 들어옵니다. 그래서 `팀원` 탭의 `담당자명`이 인트라넷 담당자 이름과 같아야 합니다.

**MP AI로 옮기는 방법**: MP AI에 그 매체가 들어오기 시작하면 보드 실적 탭에 안내가 뜹니다. 겹치는 기간은 자동으로 MP AI 숫자를 쓰므로 두 번 세지 않습니다. 시트 `설정` 탭의 `인트라넷보충매체`에서 그 매체를 지우면 완전히 옮겨집니다. 세 매체를 모두 지웠다면 **Actions → board-sync → Disable workflow**로 자동 실행을 끕니다.

### 실적 숫자 기준
- MP AI 기준이며, 위 설정 규칙(VAT, 제외 계정, 50%)을 적용해 저장합니다.
- **AHI 건강 신호**는 점수 구간표 없이, 원재료 지표가 전월보다 `설정` 탭의 경고 기준만큼 나빠지면 주의로 표시합니다.
- 유지율·성장률은 이력이 3개월, 신규 매출 비중·평균 거래 기간은 6개월 이상 쌓여야 계산됩니다. 그 전에는 '계산 불가'로 나옵니다.

### MP AI 매체 공지
팀장 알리미가 매일 MP AI 매출을 가져올 때 **MP AI 매체 공지**(네이버·지마켓·카카오·11번가 공지 요약)도 함께 가져옵니다.
- 공지사항 탭의 **매체 공지**에서 조치필요·영업기회·참고로 나눠 봅니다.
- **확인 팝업(1시간 재알림)은 '조치필요' 중 최근 게시(`매체공지확인일`, 기본 7일)이거나 신청 마감이 남은 것만** 대상입니다. 다만 `매체공지확인제외유형`(기본 `프로모션·이벤트`)은 확인 없이 목록으로만 보여줍니다. 이 값을 비우면 조치필요 전부가 확인 대상이 됩니다.
- 조치필요·영업기회의 **신청 마감일은 캘린더에 자동으로 표시**됩니다(오늘 이후만, 하루에 여러 건이면 한 칸으로 묶음).
- 보여줄 매체는 `설정` 탭 `매체공지매체`에서 바꿉니다.

## 4. 운영 규칙 요약

- **목표**: 팀원이 작성하면 `승인 대기` 상태가 됩니다. 팀장이 승인하면 진행됩니다. 팀원이 승인된 목표를 고치면 다시 승인을 받아야 합니다.
- **일일 체크**: 달성 또는 실패로 기록합니다. 실패하면 **사유가 필수**이고, 팀장이 이야기를 나눈 뒤 **소통완료**를 체크합니다. 목표 수치는 자동으로 바뀌지 않습니다.
- **캘린더**: 일정, 목표 마감, 일일 달성(✓)·실패(✗)가 자동으로 표시됩니다. 인트라넷 **근태·외근**(지난 31일~앞으로 62일)도 매일 오전 인트라넷 보충 때 함께 들어옵니다. 지각·조퇴·결근은 본인과 팀장에게만 보이고, 인트라넷 일정은 보드에서 고칠 수 없습니다(인트라넷에서 고치면 다음 날 반영).
- **월별 평가자료**: 액션플랜 탭이나 팀 현황 탭에서 엑셀로 받습니다. 시트는 요약, 목표 달성, 일일 기록, 매체별 매출, 계정별 매출 5개입니다. 팀원은 본인 자료만 받을 수 있습니다.
- **팀장 전용 탭 추가**: `Code.gs`의 `TABS` 목록에 `{ id: '...', name: '...', lead: true }`를 한 줄 추가하고, 화면 함수를 만들면 됩니다.

## 5. 한계 (미리 알아둘 것)

- 근무일은 월~금으로 계산하고, 공휴일은 빼지 않습니다.
- 알리미와 MP AI 수집은 크롬이 켜져 있어야 동작합니다. 모바일에서는 알림이 오지 않고, 보드를 열었을 때만 팝업이 뜹니다.
- 앱스 스크립트 무료 한도(하루 실행 시간 90분)는 팀 규모에서는 여유가 있습니다.
