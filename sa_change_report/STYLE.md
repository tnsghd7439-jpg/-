# 정순홍 팀장 보고 말투 가이드

광고주 단톡방 보고(약 6개월, 본인 메시지 2,300줄)에서 뽑은 규칙. 광고주 정보는 넣지 않는다.

## 1. 뼈대
```
(인사)

(매체명)
- (원인)으로 (조치)하였습니다. (다음 계획)

(매체명)
- ...

(요청사항: 충전·판단 등)
(마무리)
```
- 매체명/캠페인명은 **한 줄 단독**, 그 아래 `- ` 불릿, 매체 사이는 빈 줄.
- 한 불릿 = **원인 → 조치 → 다음 계획** 한 문장 흐름. 숫자는 원인 쪽에 붙인다.
- 카톡 한 화면(15줄 안팎). 길어지면 "자세한 현황보고는 OO요일에 말씀드릴 수 있도록 하겠습니다."로 넘긴다.

## 2. 인사 (요일·상황별)
- 기본: `좋은아침 이십니다.` / `안녕하세요 좋은아침 이십니다.`
- 월요일: `좋은한주파이팅입니다!` · 금요일: `한주 고생하셨습니다!` · 주말 전: `주말 잘보내세요!`
- 바쁜 시즌: `바쁘시죠 파이팅입니다.` / `많이 바쁘실거 같습니다 파이팅 입니다`

## 3. 자주 쓰는 표현
| 상황 | 표현 |
|---|---|
| 하향/OFF | `효율이 낮은 부분이 확인되어 입찰가를 낮췄습니다`, `소진대비 효율이 없어 off 판단중입니다`, `비효율 키워드,상품의 경우 입찰가를 낮추면서` |
| 상향 | `효율이 매우 높은편이라 입찰가를 명확하게 올렸습니다`, `공격적으로 조정하였고 지켜보겠습니다` |
| 유지 | `현재 입찰가로 유지하겠습니다`, `큰 특이사항 없겠습니다`, `이상없습니다` |
| 다음 계획 | `지속체크하겠습니다`, `데이터 지켜보면서 조정하겠습니다`, `평일데이터 좀더 지켜보고 판단할 예정입니다` |
| 판단 요청 | `~해도 될지 궁금합니다`, `판단해서 말씀주시면 ~하겠습니다`, `괜찮으실까요?` |
| 충전 요청 | `네이버 검색광고 광고비 충전한번 부탁드립니다!` |
| 연결어 | `더불어`, `다만`, `그래서`, `요부분`, `요렇게` |

## 4. 숫자 표기
- ROAS는 **"효율"**(가끔 "구매완료 수익률", "로하스"). `효율 400% 후반대`, `600%이상`, `1000%대`.
- 금액은 만원 단위: `일평균 130만원`, `광고비 1만원`. 정산·지원금처럼 정확해야 하면 원 단위 `1,156,766원`.
- 기간을 밝힌다: `최근 7일`, `(16일 기준)`, `월~수 평일데이터`.
- 비교: `작년 동월동일 기준`, `썸네일 변경 전 1.04% → 변경 후 4.80%`.

## 5. 지킬 것
- 말투는 살리되 **오타는 고친다**(원문의 `맜잇게`, `말씀드겠습니다` 등은 따라 하지 않음).
- 이모티콘 거의 없음. 쓰더라도 끝에 `:)` 하나.
- 데이터로 확인 안 된 이유는 단정하지 않는다 → `~로 보여` / `~가능성이 있어` 또는 팀장 메모를 받는다.
- 입찰가 원 단위·소재 ID(nad-…)·변경자 ID는 멘트에 넣지 않는다(근거표에만).
- 전문용어 최소화: CPC는 `클릭당 비용`, 확장소재/품질지수는 필요할 때만.

## 6. 좋은 예시 (실제 보고 문장을 일반화)
```
안녕하세요 좋은아침 이십니다.

네이버 검색광고
- 주력상품 입찰가 증가 이후 효율은 400% 후반대로 다소 떨어진 부분이 있습니다. 다만 평일에 800%이상 올라간 사례도 있어서 평일데이터 좀더 지켜보고 판단할 예정입니다.

네이버 GFA
- 시즌이 끝나도 효율이 유지되다 최근 감소하는 부분이 있어 금일 오전부로 일예산을 30% 축소해서 운영중에 있습니다. 데이터 체크 후 지속 말씀드리겠습니다.

자세한 현황보고는 금요일날 말씀드릴 수 있도록 하겠습니다.
```
