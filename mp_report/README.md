# 6팀 일일 점검 자동화

인트라넷(work.mymp.co.kr)에서 아래 5개 항목을 수집해 구글챗으로 요약을 보냅니다.

1. 신규 / 신규+이관 / 피이관 (당월 누적)
2. 전월 매출이 발생했지만 광고주 정보가 비어 있는 광고주
3. 광고비 소진중단·하락 광고주 (기준일 vs 직전 7일 평균, 일평균 1만원 미만 제외, 30% 이상 하락)
4. 쿠팡·메타·구글 전월 수수료/세금계산서 업무요청 누락 (매월 7일 기한, 신규 추적 광고주 🆕)
5. 외근·근태 현황 (오늘~이번 주 일요일)

## 실행

```bash
bash mp_report/setup.sh
python3 mp_report/collect.py            # 수집 + 구글챗 전송
python3 mp_report/collect.py --dry-run  # 전송 없이 확인
```

필요한 환경변수: `MP_ID`, `MP_PW`, `GCHAT_WEBHOOK`
구글 시트 누적(선택): `GSHEET_WEBAPP`, `GSHEET_TOKEN` — 설치 방법은 `sheet_append.gs` 상단 주석 참고

## 기준일
인트라넷은 전일 매출을 당일 오전(약 10시)에 집계합니다. 3번 광고비 점검은 팀 합계가 정상 수준으로
집계된 가장 최근 날짜를 자동으로 기준일로 사용합니다(어제 미집계 시 전전일).
(공개 저장소이므로 계정·웹훅·수집 결과는 절대 커밋하지 않습니다. 결과는 `output/`에 저장되며 git에서 제외됩니다.)
