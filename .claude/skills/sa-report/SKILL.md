# 변경이력 → 광고주 보고 멘트

1. 광고주를 확인한다. `sa_change_report/advertisers.json`에 있으면 `--advertiser`, 없으면 customerId를 묻는다
   (API로 광고주 목록 조회는 안 됨). 기준 효율을 모르면 400%로 하고 그렇게 했다고 알린다.
2. 실행: `python3 sa_change_report/report.py <파일> --customer <ID> [--target N] [--memo "캠페인|하향=이유"]`
3. 출력의 "이유 확인 필요" 항목이 있으면 사용자에게 한 번에 묶어서 묻고, 답을 `--memo`로 넣어 다시 실행한다.
   사용자가 "그냥 써"라고 하면 이유 없이 조치만 쓴다. 이유를 지어내지 않는다.
4. 초안을 [sa_change_report/STYLE.md](../../../sa_change_report/STYLE.md)에 맞춰 다듬어 **복붙용 코드블록**으로 준다.
   - 근거표(csv)의 숫자만 쓴다. 입찰가 원 단위·소재 ID·변경자는 멘트에 넣지 않는다.
   - 같은 캠페인의 비슷한 조치는 한 불릿으로 합친다. 15줄 안팎.
5. 멘트 아래에 근거표 요약(캠페인/변경/변경 전 효율/근거 구분: 데이터·추정·메모)을 짧게 붙인다.
