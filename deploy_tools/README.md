# 영업6팀 도구 자동 배포

신입은 `install.bat`을 **한 번 더블클릭**하면 끝납니다.
팀장은 새 버전을 **구글드라이브 배포 폴더에 올리기만** 하면 됩니다.
그러면 팀원 PC가 켜질 때 구버전을 지우고 신버전으로 자동 교체합니다.

```
[팀장 PC] ──올리기──▶ [드라이브 배포 폴더] ◀──정리(10분마다)── [배포 서버: Apps Script]
                                                                  │ 목록·파일
                                     [팀원 PC: install.bat / PC 켤 때 자동 확인] ◀─┘
```

## 배포 대상

| 도구 | 종류 | 드라이브에 올릴 파일 이름 (규칙) | 팀원 PC에서의 위치 |
|---|---|---|---|
| 고액광고주 제안서 작성툴 | HTML | `search_ad_deck_tool`로 시작하는 `.html` (예: `search_ad_deck_tool_v32.html`) | 바탕화면 `영업6팀 도구\고액광고주 제안서 작성툴.html` |
| 보고서 다운로드 가이드 | HTML | `보고서`로 시작하고 `가이드`가 들어간 `.html` | 바탕화면 `영업6팀 도구\보고서 다운로드 가이드.html` |
| 권한분석툴 | HTML | `권한분석툴`로 시작하는 `.html` | 바탕화면 `영업6팀 도구\권한분석툴.html` |
| 영업노트 가이드 | HTML | `영업노트`로 시작하고 `가이드`가 들어간 `.html` | 바탕화면 `영업6팀 도구\영업노트 가이드.html` |
| 영업노트 (웹앱) | 웹 바로가기 | 올릴 파일 없음 (Code.gs의 `SALES_NOTE_URL`) | 바탕화면 `영업6팀 도구\영업노트 (웹).url` |
| 네이버 영업 서포터 | 크롬 확장 | `서포터`가 들어간 `.zip` (예: `네이버영업서포터_1.1.1.zip`) | `%LOCALAPPDATA%\Team6Tools\extensions\naver-sales-supporter` |
| 마케터 할 일 | PC 앱 | 올리지 않음 (`TODO_UPDATE_FILE_ID`의 기존 update.zip 사용) | 처음 한 번 설치만 하고, 이후 업데이트는 앱이 스스로 합니다 |
| 설치·업데이트 프로그램 | 자기 자신 | `install`로 시작하는 `.bat` | `%LOCALAPPDATA%\Team6Tools\updater.ps1` |

> 버전 번호는 신경 쓰지 않아도 됩니다. 파일 **내용이 바뀌었는지(지문)**로 새 버전 여부를 판단합니다.

## 1. 처음 한 번: 팀장 설정 (약 15분)

### 1-1. 드라이브 배포 폴더 만들기
1. 구글드라이브에 `6팀 배포` 폴더를 만듭니다. 주소 `.../folders/` 뒤의 값이 **폴더 ID**입니다.
2. 위 표의 파일들을 이 폴더에 올립니다.
   - 확장프로그램 ZIP은 이름을 `네이버영업서포터_1.1.0.zip`처럼 `서포터`가 들어가게 바꿔 주세요.
   - 46MB짜리 `6팀_툴_최신본` ZIP은 올리지 않습니다. 파이썬은 설치 프로그램이 python.org에서 직접 받습니다.

### 1-2. 배포 서버 만들기 (Google Apps Script)
1. https://script.google.com 에 접속해 **새 프로젝트**를 만듭니다. 이름은 `6팀 도구 배포`로 합니다.
2. `Code.gs`에 `server/Code.gs` 내용을 붙여넣습니다.
3. 왼쪽 ⚙️ 프로젝트 설정에서 **"appsscript.json 매니페스트 파일 표시"**를 켭니다. 그다음 `appsscript.json`에 `server/appsscript.json` 내용을 붙여넣습니다.
4. `Code.gs` 위쪽 설정값을 채웁니다.
   - `FOLDER_ID`: 1-1의 폴더 ID
   - `TEAM_KEY`: 영문과 숫자로 된 아무 문자열 (예: `t6-2026-xxxx`)
   - `SALES_NOTE_URL`: 영업노트 웹앱 주소 (`.../exec`)
   - `TODO_UPDATE_FILE_ID`: '마케터 할 일' `team.json`의 `update_url`에서 `id=` 뒤의 값. **꼭 채우세요.** 채워야 기존 팀원 앱의 자동 업데이트 링크가 끊기지 않습니다.
     - 현재 이 `update.zip`은 **개인 Gmail 계정 소유**이고 회사 계정에는 보기 권한만 있습니다.
       그래서 '마케터 할 일' 업데이트는 **지금처럼 Gmail 계정에서 그 update.zip을 직접 교체**하세요.
       배포 폴더에는 update.zip을 올리지 않습니다. 첫 설치용으로 읽기만 하므로 보기 권한으로 충분합니다.
5. 함수 선택에서 `checkSetup` → ▶ 실행 → 권한 허용. 로그에 도구 목록이 보이면 성공입니다.
6. `setupTrigger`를 ▶ 실행합니다. 이후 10분마다 폴더가 자동 정리됩니다.
7. **배포 → 새 배포 → 유형: 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 생성된 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> ⚠️ 액세스 권한에 '모든 사용자'가 보이지 않으면 회사 구글 관리자가 외부 공개 웹앱을 막아 둔 것입니다. 이 경우 이 방식은 쓸 수 없으니 알려 주세요. 대안은 '데스크톱용 Google Drive' 동기화 방식입니다.

### 1-3. install.bat에 주소 넣기
1. `client/install.bat`을 **메모장**으로 엽니다.
2. 위쪽 설정 두 줄을 채웁니다.
   ```
   $ServerUrl = '1-2에서 복사한 웹 앱 URL'
   $TeamKey   = 'Code.gs의 TEAM_KEY와 같은 값'
   ```
3. 저장할 때 인코딩은 **UTF-8**로 합니다 (메모장 기본값). 'ANSI'로 저장하면 한글이 깨집니다.
4. 채운 `install.bat`을 드라이브 배포 폴더에도 올립니다. 이후 이 파일을 고치면 팀원 PC의 업데이트 프로그램도 자동으로 바뀝니다.

### 1-4. 팀장 PC에서 먼저 테스트
`install.bat`을 더블클릭하고 아래를 확인합니다.
- [ ] 바탕화면에 `영업6팀 도구` 폴더가 생기고 HTML 4개와 영업노트 바로가기가 들어 있다
- [ ] 크롬 확장 등록 안내가 나온다
- [ ] '마케터 할 일'이 이미 설치된 PC라면 "이미 설치되어 있어 건너뜁니다"가 나온다
- [ ] 드라이브에 HTML 하나를 새로 올리고 10분 뒤 폴더 안 `지금 업데이트 확인`을 실행하면 교체된다

> 처음 설치할 때 바탕화면과 다운로드 폴더에 있는 예전 버전 파일(예: `search_ad_deck_tool_v30.html`)을 찾아 **휴지통으로 보낼지 물어봅니다**. 팀장 PC의 작업 원본이 목록에 나오면 `N`을 누르세요.

## 2. 신입에게 전달하는 방법

1. 드라이브 배포 폴더의 `install.bat` 링크를 보냅니다. 메일이나 메신저로 파일을 직접 보내도 됩니다.
2. 신입이 할 일:
   1. `install.bat` 더블클릭
      - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**
   2. 검은 창의 안내대로 진행 ('마케터 할 일' 설치 창이 따로 열리면 끝날 때까지 기다리기)
   3. 마지막에 나오는 **★ 직접 해야 할 일**(크롬 확장 등록) 따라 하기
      - 크롬 주소창에 `chrome://extensions` 입력 → 개발자 모드 켜기 → '압축해제된 확장 프로그램을 로드합니다' → 폴더 경로 붙여넣기 (경로는 자동으로 복사되어 있음)
3. 이후로는 신입이 할 일이 없습니다. PC를 켤 때마다 자동으로 확인하고, 바뀐 것이 있으면 화면 오른쪽 아래에 알림이 뜹니다.

## 3. 평소 업데이트 방법 (팀장)

| 하고 싶은 것 | 하는 법 |
|---|---|
| HTML 새 버전 배포 | 드라이브 배포 폴더에 새 파일을 올리기만 합니다. 이름이 달라도(`v31` → `v32`) 됩니다 |
| 확장프로그램 새 버전 | `manifest.json`의 `version`을 올리고 → 폴더째 ZIP → 배포 폴더에 올립니다 |
| 마케터 할 일 새 버전 | 지금처럼 `version.txt`와 `server.py`의 `VERSION`을 올리고, **Gmail 계정의 기존 update.zip을 새 버전으로 교체**합니다 (드라이브 우클릭 → 버전 관리 → 새 버전 업로드). 배포 폴더에는 올리지 않습니다 |
| 실수로 올린 것 되돌리기 | 드라이브에서 해당 파일 → 우클릭 → **버전 관리**에서 이전 버전을 다시 올립니다 |

- 올리고 나서 **최대 10분** 안에 드라이브 폴더가 정리됩니다. 새 파일 내용이 기존 파일에 덮어써지고, 올린 파일과 구버전은 휴지통으로 갑니다.
- 팀원 PC는 **다음에 PC를 켤 때** 받습니다. 바로 받게 하려면 바탕화면 폴더의 `지금 업데이트 확인`을 실행하라고 안내하세요.
- **완전 자동 업로드를 원하면:** 팀장 PC에 '데스크톱용 Google Drive'를 설치하고 배포 폴더를 동기화하세요. 작업 결과물을 그 폴더에 저장하는 것만으로 업로드까지 끝납니다.

## 4. 알려진 한계 (솔직하게)

- **크롬 확장 첫 등록은 사람이 해야 합니다.** 크롬이 보안상 막아 둔 부분이라 스크립트로 우회할 수 없습니다. 이후 교체는 자동이지만, 반영되려면 **크롬을 재시작**해야 합니다.
- **기존 팀원 PC의 예전 확장**은 자동으로 지울 수 없습니다. 기존 팀원은 `chrome://extensions`에서 예전 '네이버 영업 서포터'를 한 번 삭제한 뒤 새 경로로 로드해야 합니다.
- **보안 수준은 "주소와 팀 키를 아는 사람"까지입니다.** 배포 서버는 로그인 없이 응답합니다. 그래서 `install.bat`(주소와 키 포함)을 외부에 유출하지 마세요. 고객 데이터가 들어간 파일은 배포 폴더에 올리지 마세요.
- **보안 프로그램 경고:** 회사 백신이나 SmartScreen이 `.bat` 실행을 경고하거나 막을 수 있습니다. 막히면 전산팀에 예외 등록을 요청해야 합니다.
- 이 저장소는 **공개 저장소**입니다. 설정값(폴더 ID, 팀 키, 웹앱 주소)은 Apps Script 편집기와 배포용 `install.bat`에만 넣고 **절대 커밋하지 마세요**.
- 윈도우에서의 실제 실행은 개발 환경에서 테스트하지 못했습니다. 반드시 1-4의 팀장 PC 테스트를 먼저 해 주세요.

## 파일 구성

```
deploy_tools/
├─ README.md            이 문서
├─ server/
│  ├─ Code.gs           배포 서버 (드라이브 폴더 정리 + 목록·파일 응답)
│  └─ appsscript.json   Drive 고급 서비스·웹앱 설정
└─ client/
   └─ install.bat       신입 PC용 설치·업데이트 프로그램 (더블클릭)
```
