## 1. 상품명 표기기준 위반 (2506)

### 1.1 중고 상태값 미설정

아래는 반드시 `중고`로 설정.

- 리퍼(리퍼비쉬) — A/S 거쳐 재판매
- 반품 후 재판매
- 매장 전시 상품(미사용이어도 해당)
- 이동/보관 중 스크래치·하자·훼손 발생
- 개봉 후 임의 소분/재포장 — 가개통 휴대폰·태블릿·스마트워치, 데스크탑 분해 메모리, 면도날 소분 등

### 1.2 해외 상품 기준

- 해외구매대행은 **출고지를 해외로 설정** → 상품명에 `[해외]` 자동 노출
- 국내배송으로 등록 후 상세페이지에만 해외발송 기재 → 삭제
- 국내 재고 소진 시 해외 발송 → 삭제

### 1.3 모음전 등록 기준 ★ 핵심

- 상품명에 **첫 번째 옵션의 상품 정보만** 기입
- 첫 번째 옵션은 **기본 상품 가격**으로 구매 가능해야 함
- 여러 옵션 표기 / 포괄 명칭 사용 **불가**
- 예외: 식품 카테고리는 첫 옵션 표기 후 `~외 몇 종`, `~외 택 1` 두 표현만 허용 (세트상품 제외)
- 색상·사이즈·골프>샤프트강도 옵션은 가격이 같으면 상품명 미표기 가능. 표기한다면 첫 옵션만. 단 패턴·디자인·색배치 등 다른 요소가 바뀌면 적용 안 됨
- 첫 옵션 품절 시 **상품 자체를 품절 처리**. 다른 상품으로 교체 시 상품ID 재사용으로 제재

**적용 카테고리**: 가구/인테리어(24.8.27 신규 적용), 출산/육아(유아동 주얼리·언더웨어/잠옷·의류·잡화 제외), 출산/육아>위생/건강용품>유아마스크, 생활/건강, 스포츠/레저, 도서, 디지털/가전, 화장품/미용, 식품(농/축/수산물 제외)
→ 그 외 카테고리는 **적용 1개월 전 사전 공지 후** 순차 확대. 농/축/수산물도 이후 진행 검토 중
**조치**: 기준 위반 시 **상품 삭제 + 클린 프로그램 적용**

#### 1.3.1 모음전 정책 공지 상세 (FAQ 포함)

**옵션가 원칙**
- 상품명에 표기하는 **최상단 옵션은 옵션가 반드시 `0원`**. 추가금도, 마이너스 옵션가도 불가
- 2번 이하 옵션은 추가금·마이너스 옵션가 자유롭게 설정 가능
- 예: 상품명 `농심 신라면` / 옵션1 신라면(0) / 옵션2 짜파게티(+1000) / 옵션3 안성탕면(-1000)
- **도서 카테고리는 도서정가제로 마이너스 옵션 불가**
- 본품과 무관한 상품도 옵션 등록은 가능하나 연관 상품 권장

**일치시켜야 하는 항목 3가지**
1. 상품명 = 옵션1
2. **대표 이미지 = 옵션1 상품** (불일치 시 상품정보 불일치 사유로 삭제)
3. **상품정보란 `모델명` = 대표상품(상품명 표기 상품)**

**포괄 표현 금지 예시**
- `000시리즈`
- 휴대폰 케이스에서 `노트 시리즈` 등 호환 기종 포괄 명칭
- 케이스는 `케이스 모델명`+`사용 기종` 조합 옵션 등록은 가능하나, 상품명은 첫 옵션만 정확히 지칭

**조합형 옵션은 구성 그대로 표기 시 허용**
- 상품명 `AA마스크 KF94_대형 흰색 10매` / 옵션1 동일 / 옵션2 `AA마스크 KF94_소형 블랙 10매` → 허용
- 사이즈·크기·수량이 여러 개 조합되어 있어도 첫 옵션 구성 그대로면 OK

**직접입력형 옵션**
- 상품 선택 용도로는 **사용 불가** (상품명과 첫 옵션을 일치시킬 수 없으므로)
- 각인 문구 등 제작 상품의 부가 입력은 사용 가능

**색상·사이즈 예외의 정확한 범위**
- 예외는 **가격이 모두 같을 때만** 적용
- 표기하려면 첫 옵션만. 다른 옵션은 가격이 같아도 표기 불가 → 표기하고 싶으면 **별도 상품으로 분리**
- 판단 기준은 옵션명이 아니라 **실제 상품이 색상·사이즈만 변경되는지 여부**. 제조사가 색상이라 불러도 네이버는 그 기준을 따르지 않음
- 투톤·패턴·색배치 등 다른 디자인 요소가 바뀌면 예외 미적용
- 참고: 색상·사이즈를 검색하는 사용자도 많으므로 **제외보다 첫 옵션 표기가 유리**

**품절 처리**
- 옵션1 품절 → 다른 옵션 재고와 무관하게 **상품페이지 자체를 품절 처리**
- 다른 옵션으로 교체 판매 → **상품 ID 재사용**으로 제재
- 재고 연동으로 품절 처리가 불가한 상품은 `풀필먼트 설정안함`으로 변경 후 품절 처리

**상품 ID 재사용 예외 (중요)**
- 정책 대응을 위한 **최초 1회 수정에 한해** 상품ID 재사용으로 제재하지 않음
- 모음 상품명 → 단일 상품명 변경은 재사용에 해당하지 않음. 단 해당 옵션이 ①옵션 1번 ②추가금 없는 기본가여야 함
- 상품명에 대표상품이 **미기재**였던 경우: 옵션 순서 변경 후 추가금 없는 첫 옵션을 표기. 이후 변경 시 제재
- 상품명에 대표상품이 **기재**되어 있던 경우: 그 상품을 옵션1로 옮기고 추가금 0원으로 가격 조정. 이후 대표상품 변경 시 제재

### 1.4 그룹상품 기준

- **4.1** 카테고리·브랜드/제조사·상품명·스펙·구성이 동일한 상품만 한 그룹
  - 위반 예: 스틱형/캡슐형 비타민을 한 그룹으로
- **4.2** 상품명에 사은품 기재 금지 → 상세설명 및 `구매/혜택 조건>사은품`에 입력, 노출 원하면 추가문구 사용
  - 위반 예: `다우니 라벤더 세제 미니세제 증정`, `(1개 추가증정) 다우니 라벤더 세제`
- **4.3** 그룹 내 판매옵션 단위 통일 (예: `20포`와 `10캡슐` 혼용 불가)
- **4.4** 상품명에 옵션 정보 중복 기재 금지 (예: `1개 2개 3개 4개`) → 그룹 및 하위 옵션 전체 삭제 가능

## 2. 정보부족/상이 — 모델명 등 (2505)

### 2.1 무관 키워드 기재

상표권 등록 브랜드, 연예인 이름, 프로그램명 무단 사용 → **삭제**. `브랜드명+유사/대체/대응`도 삭제 대상.

**대체어 변환표**

| 금지 | 대체 |
|---|---|
| 크록스(CROCS) | 클로그 |
| 털크록스 | 털클로그 |
| 지비츠 | 파츠, 참 |
| 어그부츠 | 양털부츠 |
| 어그슬리퍼 | 양털슬리퍼 |
| 레고 | 블록 |

**한복 관련 삭제 예시**: `중국 한푸(Hanfu) 전통 한복`, `한복 당나라 코스프레`, `기모노 한복 개량`, `중국풍/일본계/유카타 한복`, `소수민족 한복`. 한복이 아닌 상품에 한복 키워드 기재도 삭제.

### 2.2 무관한 제조사/브랜드/모델명 기입

- 비브랜드 휴대폰 케이스에 기종 제조사/브랜드 기입
- 맥심 모카골드 판매 상품에 판매자 정보 기입

### 2.3 소모품 및 호환 제품 `[호환]`

- **정품**: 본품 제조사 또는 제조사 승인 제조대행사 생산품만
- 그 외는 전부 **호환용**
- **소모품 정의**: 청소기 필터/먼지봉투/교체용배터리, 공기청정기 필터, 커피캡슐 등 주기적 교체 부속품
  - 예외: 복합기·프린터 잉크/토너는 `정품`/`재생`으로 구분
- 호환용은 상품명에 `정품` 표기 불가
- 호환용 **소모품**은 상품명 앞에 `[호환]` 필수

### 2.4 병행 상품 `[병행]`
적용: 디지털/가전, 스포츠/레저>골프클럽

- **병행**: 정식업체가 아닌 제3업체 수입품(내수·직수입 포함)
- **정품**: 외국업체와 국내업체 공식계약 또는 외국업체 국내법인 직수입
- 병행은 상품명 앞 `[병행]` 필수

### 2.5 대여 `[대여]` / 렌탈

**대여**: 1회성 대여 후 반납. 상품명 앞 `[대여]`, 가격은 부가세 포함 대여료.

**렌탈**: 스마트스토어 렌탈 솔루션 이용 판매자만 가능(그 외 금지)
- 상품명·이미지가 특정 모델 1개를 명확히 지칭. 포괄 명칭 불가
- 별도 옵션 선택 없이 구매 가능하거나 최상단 옵션이 상품명 상품
- 상품명에 **브랜드명 + 모델명 + 의무사용기간** 필수
- 가격은 **월 렌탈료** 기준

| 판정 | 예시 |
|---|---|
| O | LG 퓨리케어 냉온정수기 WD502AW 의무3년 |
| O | LG 퓨리케어 냉온정수기 WD502AW 의무기간없음 |
| X | 렌탈 냉온정수기 의무3년 (브랜드·모델명 없음) |
| X | ~ WD502AW, WD505AS 의무3년 (2개 이상) |
| X | ~ WD502AW 외 의무3년 (포괄 명칭 '외') |

적용 카테고리: 디지털/가전>생활가전>세탁/건조기, 주방가전>냉장고, 주방가전>정수기, 계절가전>공기정화기>공기청정기, 생활/건강>안마용품>안마의자, 생활/건강>욕실용품>비데/비데용품, 가구/인테리어>침실가구>매트리스 (수시 변경)

### 2.6 렌터카

- **장기 렌터카(2개월 이상 계약) 취급 불가**
- 단기: 상품명에 이용지역·차종·연식·연료타입·인승·주말or평일·보험사양 **필수**, 이 외 텍스트 사용 불가
- 가격 = 해당 요일 차량 이용료 + 필수 보험료 (24시간 기준)

예: `[제주/평일] 22년식 G80, 가솔린, 5인승, 기본자차` / 150,000원 / 옵션으로 고급자차 +3,000, 주말 +30,000

### 2.7 그룹상품 옵션

- **7.1** 네이버 제공 옵션값이 있는데 수동 중복 등록 → 삭제 가능. 상품명에 옵션값 중복 입력도 제재
  - 예: 수량 `1개` 옵션 등록 + 상품명에도 `1개` 기재
- **7.2** 카테고리별 지정 단위 준수 (cm만 제공하는데 mm 등록, 2.5L를 2500ml로 등록 → 위반)
- **7.3** 옵션명과 무관한 옵션값 금지
  - `용량` 옵션에 `1개/2개`, `사이즈` 옵션에 `화이트/블랙`, `맛` 옵션에 `품종/원산지`

## 3. 가격 / 배송비 기준 위반 (2503)

### 3.1 가격 어뷰징

| 항목 | 내용 |
|---|---|
| 1.1 | 옵션 추가금 조정으로 노출가 낮춤. 상품명 대표상품에 추가금 설정 / 낱개가×수량보다 비싼 수량옵션 / 옵션값에 `문의하세요` 등 무관 문구 |
| 1.2 | 쿠폰 어뷰징 — **누구나 노출가에 추가조건 없이 구매 가능해야 함** |
| 1.3 | 오픈박스·벌크·B급·진열상품을 기본가로, 정상품에 추가금 |
| 1.4 | 발송시점에 따라 추가금 / 지연발송 상품을 기본가로 |

## 5. 원부 및 카테고리 오매칭 (공지)

> **삭제된 상품은 복구되지 않음. 올바른 카테고리로 신규 등록해야 함.**

### 5.1 비도서 카테고리에 도서 등록 → 삭제(판매금지)

**도서 카테고리 등록 대상**
1. ISBN 번호 있는 상품 — `97~`, `98~`로 시작하면 도서로 취급
2. ISBN 없거나 정가제free 상품 중 도서 관련 상품군
   - 유아도서: 헝겊책, 플레이북, 초점책, 사운드북
   - 교육도서: 교정본, 글씨교정책, 워크북
   - 취미도서: 컬러링북, 악보책, 아트북

### 5.2 중고 상품을 새상품 카테고리에 등록

**중고 카테고리 리스트**
- 스포츠/레저>골프>로스트볼
- 디지털/가전>휴대폰>공기계/중고폰
- 도서>잡지>어학/고시/교육>중고학습
- 도서>중고도서>도서
- 도서>중고도서>만화

### 5.3 레슨/강습 상품을 타 카테고리에 등록

- **상품판매권한** 받은 판매자만 허용
- 결제 후 **1개월 이내 서비스 제공 완료 + 300만원 미만**만 가능
- 등록 카테고리: `여가/생활편의>예체능 레슨` 계열(피트니스/PT, 필라테스/요가, 골프레슨, 구기스포츠, 무예/무도, 아웃도어스포츠(스키/보드·서핑/다이빙·기타), 댄스/무용, 보컬/악기, 미술, 기타) 및 `여가/생활편의>자기계발/취미 레슨` 계열(외국어(영어·기타), 공예, 뷰티, 커피/요리, 취업/자격증, 기타)

## 6. 판매행위위반 — 기타 (공지)

### 6.1 거짓 할인율

- 전자상거래법 제21조제1항제1호, 표시광고법 제3조제1항, 공정위 **온라인 다크패턴 가이드라인** 위반
- 실제와 다른 과도한 할인율 등록 → 상품 또는 **판매자** 제재
- **옵션 추가금 제한 회피 목적의 할인율 부풀리기도 제재 대상**
- 실제 사례: 스마트스토어 할인 전 389,900원(89%) vs 타 판매처 78,900원(49%)

### 6.2 상품이 아닌 결제창 등록
개인 결제창 / 테스트 상품 / 배송비·차액 수수료 결제창

### 6.3 연예인 퍼블리시티권 침해
계약 없이 연예인 이름·프로그램명을 상품명에 기재하거나 이미지 무단 사용

### 6.4 소명 방법

- 제출 대상: 할인 전 가격인 **`판매가`의 근거**
  - 공식 홈페이지에서 할인 전 가격으로 판매되는 URL + 화면 캡처
  - 기존 스마트스토어에서 해당 가격으로 판매된 이력 캡처 + 주문번호
- 접수 경로: **1:1문의하기 → 문의유형 `신고하기 > 상품등록 기준위반`**
- 옵션가 설정 때문에 할인을 높인 경우 → 실제 할인율로 등록하고, 등록 불가 가격의 옵션은 **별도 상품으로 분리**
